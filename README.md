3. Astral Party가 종료된 상태에서 `dist\MegasBulletCalculator.exe`를 한 번 직접 실행합니다.
4. 프로그램이 게임 설치 경로를 확인하고 BepInEx 및 Megas Bullet Sensor를 자동 설치·복구합니다.
5. 이후 잠재능력을 해금한 **메가스로 PvE 본게임**에 진입하면 계산기 오버레이가 자동 실행되고, 해당 판이 끝나면 자동 종료됩니다.

**v1.0.0에서 업데이트할 때:** 게임과 Calculator를 모두 종료하고, 기존 `dist` 폴더를 새 배포본의 `dist` 폴더로 교체한 후 **새 `MegasBulletCalculator.exe`를 한 번 실행**해 주세요. 기존 버전을 제거 프로그램으로 먼저 삭제할 필요는 없습니다. 기존 사용자 설정은 별도의 로컬 설정 경로에 저장됩니다.

## 프로그램 개요

Megas Bullet Calculator는 메가스의 현재 손패·배틀 카드 코스트와 게임의 로컬 상태를 읽어 플레이 판단에 도움이 되는 정보를 표시하기 위해 제작된 비공식 개인용 도구입니다.

**Megas Bullet Sensor**가 BepInEx를 통해 Astral Party 클라이언트의 로컬 IL2CPP 런타임 상태를 읽고, 이를 `127.0.0.1` 로컬 UDP로 Calculator에 전달합니다. 포격 대상은 게임의 유효 대상 판정을 활용합니다.

현재 구현에는 **게임 서버 패킷 가로채기·변조, 네트워크 트래픽 조작, 자동 입력·매크로·자동 플레이, 재화·전투 결과·게임 런타임 수치 변경 기능이 없습니다.** 다만 Sensor가 게임 프로세스에 로드되는 비공식 모드 방식이며, 게임사 공식 승인이나 무제재 보증을 의미하지 않습니다.

## 지원 / 검증 환경

- Windows 10/11
- Astral Party Steam Global/INT 클라이언트, PvE 모드
- 로컬 플레이어가 **잠재능력을 해금한 메가스**로 플레이하는 환경
- **게임 전체화면 · 주 모니터 · 1920×1080 (16:9)** 권장

창모드는 지원하지 않습니다. 일부 무테두리·특수 창 구성, 비표준 Windows DPI, 비16:9 해상도, 보조 모니터 등에서는 화면상 표적 위치가 어긋날 수 있고 정상 작동을 보장하지 않습니다.

## 주요 기능

- **상단 HUD A:** 현재 손패 장수와 배틀 카드 코스트 합계를 간결하게 표시
- **상단 HUD B:** 현재 라운드, 다음 라운드 시작 시 예상 손패 및 보급 안내 표시
- **HUD C 상세:** 포격 계산식, 현재 탄창·다음 라운드 손패별 상세, 스킬 사용 중 대상 후보 표시
- **우측 사이드 UI:** 전투·상점·카드 버리기·송금 등의 비통상 화면에서 전용 정보를 표시하며, 기본적으로 접힘
- **포격 대상 마커:** 선택 발판에서 포격 대상이 될 수 있는 몬스터를 화면 내·외에 시각적으로 표시
- **스킬 상태:** 준비 완료 및 쿨타임 상태 표시
- **다음 라운드 손패 예측:** 턴 종료 효과 및 게임에서 확인한 라운드 보급 보상 반영
- **개인 설정:** 표시 방식 3종, UI 투명도 조절, 카메라 이동 중 표적 숨김, 설정 초기화
- **자동 실행·종료:** 메가스로 PvE 본게임 진입 시 자동 실행, 판 종료 시 자동 종료
- **현지화:** 한국어 / English / 日本語 / 简体中文
- **Shushu Shield Indicator 병행 사용** 지원

## 포격 계산식

현재 손패 장수를 `H`, 배틀 카드 코스트 합계를 `C`라고 할 때:

```text
예상 포격 횟수 = floor(H / 2)
예상 발당 피해 = 3 + ceil(C / 3)
예상 총 피해   = 예상 포격 횟수 × 예상 발당 피해
```

이 수치는 현재 손패·카드 코스트를 바탕으로 계산한 예상치입니다. 화면 내 표시되는 색상 등급은 예상 수치의 가독성을 위한 보조 표현입니다.

## 다음 라운드 손패 예측

- 현재 손패와 턴 종료 효과(천공위성·스마트워치·메가스 패시브 등)를 계산에 반영합니다.
- **3의 배수 라운드 보급**에서 실제 게임 UI의 카드/스타코인 보상 종류를 구분하고, 카드 보상 장수를 합산합니다.
- 이미 반영된 카드 보급을 다음 라운드 예상 손패에 중복으로 더하지 않도록 처리합니다.
- 손패 경우의 수 등 상세 정보는 HUD C 또는 우측 사이드 UI에서 확인할 수 있습니다.

## 예상 포격 대상 표시

메가스의 스킬로 **착지 발판을 실제 선택하고 있을 때** 선택 발판을 기준으로 그래프 거리 6 이내 후보를 구한 다음 게임의 유효 대상 판정을 통과한 몬스터만 표시합니다.

- **화면 안 후보:** 빨간색 타겟 마커
- **화면 밖 후보:** 화면 가장자리의 방향 표시와 몬스터 이름
- **HUD C / 우측 사이드 UI:** 후보 몬스터 이름 및 현재 HP
- **범위 표시 옵션:** 선택 발판 기준 미사일 아이콘 및 거리 `+1`~`+6` (기본 OFF)

표적 마커와 미사일 거리 표시는 상단 HUD와 우측 사이드 UI보다 뒤쪽 레이어에 표시됩니다.

> 표시되는 목록은 **실제 명중 대상의 예언이 아니라 무작위 포격 대상으로 선정될 수 있는 유효 후보군**입니다. 실제 공격 대상은 그 후보들 중 무작위로 결정됩니다. 후보 목록에는 거리 수치가 표시되지 않습니다.

카메라 이동 중 화면 표적 표시를 일시적으로 숨기는 옵션이 기본으로 켜져 있습니다. 이는 반복 합성에 따른 불필요한 화면 갱신 부담을 줄이기 위한 기능이며 표적·범위 옵션의 저장값은 변경하지 않습니다.

## Calculator UI 구성

### 상단 HUD A / B / C

- **A:** 현재 손패와 배틀 카드 코스트 합계
- **B:** 현재 라운드·다음 라운드 예상 손패·보급 알림
- **C:** A 또는 B의 추가 설명·상세 수치·스킬 포격 후보 목록. 평상시에는 숨겨집니다.

A/B를 클릭하면 해당 HUD C 상세 정보가 고정되며, 같은 패널을 다시 클릭하거나 펼쳐진 C를 클릭하면 고정을 해제할 수 있습니다. `Z`/`X`키를 누르고 있는 동안에도 일시적으로 세부 정보를 확인할 수 있습니다. 스킬 발판 선택 중에는 대상 후보 상세가 우선 표시됩니다.

### 우측 사이드 UI

전투·상점 등에서 표시되는 고정형 UI입니다. 화면 오른쪽 끝에 붙어 있으며, 탭을 클릭해 펼치거나 접습니다. `C`키를 누르고 있으면 펼쳐지고 **놓으면 접힙니다**. `C`키를 누른 동안에는 탭 클릭으로 펼침 상태를 전환할 수 없습니다.

### UI 표시 방식

| 모드 | 표시 정책 |
|---|---|
| **혼합 사용 (기본)** | 일반 보드에서는 상단 HUD, 전투·카드 버리기·상점·송금에서는 우측 사이드 UI |
| **HUD UI만 사용** | HUD가 허용되는 화면에서 상단 HUD만 표시하고, 우측 사이드 UI가 필요한 화면에서는 숨김 |
| **우측 사이드 UI만 사용** | 계산 정보 표시가 허용되는 화면에서 우측 사이드 UI 사용 |

혼합 사용 모드에서 **우측 사이드 UI 상시 표시**를 켜면 일반 보드에도 HUD와 함께 사이드 UI를 표시할 수 있습니다.

일부 게임 메뉴·임무 정보·도감·설정·결과 화면에서는 전체 계산 UI를 숨깁니다. 게임의 미니맵을 연 동안에는 상단 HUD A/B를 유지하고 HUD C 상세만 숨깁니다.

## 조작 및 단축키

단축키는 **Astral Party가 활성 창일 때** 동작합니다.

| 키 | 동작 |
|---|---|
| `Z` | **누르는 동안** HUD A(현재 손패·포격) 상세 표시 |
| `X` | **누르는 동안** HUD B(다음 라운드 손패) 상세 표시 |
| `C` | **누르는 동안** 우측 사이드 UI 펼침, 떼면 접힘 |
| `V` | 게임 화면 포격 범위 미사일 아이콘 및 거리(`+N`) 표시 ON/OFF |
| `B` | 전체 Calculator/타겟 오버레이 표시·숨김 토글 |

상단 HUD A/B는 마우스로 클릭해 세부 내용을 고정할 수 있고, 우측 사이드 UI의 탭도 클릭해 펼치거나 접을 수 있습니다. C키는 HUD 상세 창을 닫는 단축키가 아닙니다.

## 기본 설정

Windows **시스템 트레이의 Megas Bullet Calculator 아이콘을 우클릭**하여 설정과 언어를 변경합니다.

- 표시 언어: **한국어** (영어·일본어·중국어 선택 가능)
- UI 표시 방식: **혼합 사용**
- 혼합 사용 시 우측 사이드 UI 상시 표시: **OFF**
- UI 투명도: **85%** (50~100% 조절, 계산 UI에 적용)
- 게임 화면 타겟 마크: **ON**
- 포격 범위 미사일 아이콘 및 거리(`+N`): **OFF**
- 카메라 이동 중 표적 표시 숨기기: **ON**
- 우측 사이드 UI: 기본 접힘

**설정 초기화**는 UI 관련 기본값을 복원하지만, 선택한 언어와 게임 설치 경로는 유지합니다. 기존에 저장된 설정이 있으면 최초 실행 기본값보다 기존 설정이 우선합니다.

## 최초 실행 및 자동 설치

처음 사용하는 PC에서는 `MegasBulletCalculator.exe`를 직접 한 번 실행하세요. 프로그램은 Steam 설치 위치 및 라이브러리 정보를 바탕으로 `astralparty_int.exe`가 있는 게임 폴더를 탐색하고, 필요한 BepInEx Unity IL2CPP 구성요소 및 Megas Sensor를 설치하거나 복구합니다.

설치·업데이트가 필요한 시점에 게임이 실행 중이면 파일 변경을 보류하고 게임이 완전히 종료되면 처리합니다. 게임 경로를 찾지 못한 경우에는 Steam에서 설치 위치를 확인하고 다시 실행하세요.

게임 경로 또는 Calculator EXE 위치를 옮겼다면 새 위치의 Calculator를 한 번 직접 실행해 설치·경로 등록을 다시 확인하는 것이 좋습니다.

## 자동 실행 및 종료

- 게임 클라이언트에서 **메가스로 PvE 본게임**에 진입하면 Sensor가 Calculator를 자동 실행합니다.
- 해당 판이 끝나면 Calculator도 자동 종료됩니다.
- 로컬 플레이어가 다른 캐릭터인 경우에는 메가스 계산기 자동 실행 대상으로 취급하지 않습니다.

## 기존 BepInEx / Shushu Shield Indicator 사용자

이미 호환되는 BepInEx 코어가 설치되어 있다면 가능한 한 유지하고 **Megas Bullet Sensor를 별도 플러그인으로 배치**합니다. Shushu Shield Indicator와 병행 사용하도록 설계되어 있으며, 업데이트·제거 시 공유 BepInEx와 타 도구의 플러그인을 임의로 삭제하지 않도록 처리합니다.

Megas Sensor의 설치 경로는 다음과 같습니다.

```text
Astral Party 게임 설치 경로\BepInEx\plugins\MegasBulletCalculator\MegasBulletSensor.dll
```

모드와 게임 버전의 조합에 따라 예외가 있을 수 있으므로 실제 실행 환경에서 호환성을 확인해 주세요.

## 제거

1. Astral Party와 Calculator를 모두 종료합니다.
2. `dist\MegasBulletCalculator_Uninstall.exe`를 실행합니다.
3. 확인 절차를 진행하면 프로그램이 설치한 Megas Sensor와 로컬 설정 및 등록 정보가 제거됩니다.
4. 제거가 완료되면 **Calculator를 압축 해제했던 `dist` 폴더를 직접 삭제**할 수 있습니다.

BepInEx를 이 프로그램이 최초로 설치했고 다른 모드가 감지되지 않는 경우에는 해당 구성요소도 정리할 수 있습니다. 공유 BepInEx나 다른 플러그인이 있는 경우에는 보존하도록 설계되어 있습니다.

## 개인정보 / 통신

프로그램은 게임 설치 경로를 알아내기 위해 로컬 Steam 설정/라이브러리 정보를 확인할 수 있으며, 게임 상태는 **`127.0.0.1`의 로컬 UDP**를 통해 Sensor에서 Calculator로 전달됩니다. 원격 서비스로 사용자 정보를 전송하기 위한 기능은 포함되어 있지 않습니다.

사용자 설정 및 Calculator 로그는 다음 위치에 저장될 수 있습니다.

```text
%LOCALAPPDATA%\MegasBulletCalculator\
```

Sensor 로그는 게임 설치 폴더의 BepInEx 로그 경로를 이용합니다.
