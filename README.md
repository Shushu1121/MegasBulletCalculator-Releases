# Megas Bullet Calculator

Astral Party의 PvE 플레이 중 로컬 플레이어가 **메가스**를 사용할 때  
현재 손패와 배틀 카드 코스트를 바탕으로 포격 예상값, 예상 포격 대상, 다음 라운드 시작 시 예상 손패를 표시하는 Windows용 비공식 보조 오버레이입니다.

## 빠른 사용 안내

1. Releases의 Assets에서 `MegasBulletCalculator_v1.0.0_Windows.zip`을 다운로드합니다.
2. ZIP을 원하는 위치에 압축 해제합니다.
3. Astral Party가 종료된 상태에서 `dist\MegasBulletCalculator.exe`를 한 번 실행합니다.
4. 프로그램이 필요한 BepInEx / Sensor 설치 또는 복구를 진행합니다.
5. 이후 잠재능력을 해금한 메가스로 PvE 본게임에 진입하면 Calculator가 자동으로 실행됩니다.
6. 메가스 판이 끝나면 Calculator도 자동 종료됩니다.

게임이 이미 실행 중이고 설치 또는 갱신이 필요한 경우에는 게임 파일 변경을 보류하며, 게임 종료 후 다시 실행하면 설치/복구를 완료할 수 있습니다.

## 프로그램 개요

Megas Bullet Calculator는 Astral Party PvE에서 잠재능력을 해금한 메가스를 플레이할 때 계산하기 번거로운 포격 수치와 다음 라운드 손패 예상값을 화면에 보조 정보로 표시하기 위한 비공식 개인용 도구입니다.

메가스의 잠재능력으로 활성화되는 액티브 스킬로 착지 발판을 선택하는 동안에는 게임 자체 판정을 이용해 현재 선택한 발판 기준의 **유효 포격 대상 후보**를 표시할 수 있습니다.

프로그램은 BepInEx 플러그인인 Sensor가 게임 클라이언트의 로컬 런타임/IL2CPP 상태를 읽고, 그 결과를 `127.0.0.1` 로컬 UDP로 Calculator에 전달하는 구조입니다.

현재 구현에는 다음 기능이 없습니다.

- 게임 서버 패킷 가로채기/변조/위조
- 네트워크 트래픽 조작
- 자동 입력/매크로/자동 플레이
- 게임 수치, 재화, 전투 결과 또는 런타임 상태 변경

단, BepInEx와 Sensor가 게임 프로세스에 로드되는 비공식 모드 방식이므로 게임 개발사/배급사가 공식적으로 승인한 도구라는 의미는 아닙니다.

## 지원 / 검증 환경

- Windows 10/11
- Astral Party Steam Global/INT 클라이언트
- PvE 모드
- 잠재능력을 해금한 상태의 메가스
- **주 모니터 전체화면 환경 권장**
- **1920×1080 (16:9) 권장**

**창모드는 지원하지 않습니다.** 게임 화면상의 발판/몬스터 좌표와 Windows 오버레이 좌표를 맞춰 표시하는 구조이므로 창모드에서는 타겟 마크, 포격 범위, 화면 밖 대상 표시 등의 위치가 정상적으로 맞지 않을 수 있습니다.

또한 비16:9 해상도, 비표준 Windows 화면 배율(DPI), 게임이 주 모니터가 아닌 다른 모니터에 표시되는 환경에서는 오버레이 위치가 어긋날 수 있으며 정상 작동을 보장하지 않습니다.

- 현재 손패 / 효과 카드 / 배틀 카드 상태 실시간 추적
- 예상 포격 횟수, 발당 피해, 총 피해 계산
- 다음 라운드 시작 시 예상 손패 계산

- 카메라 이동 중 표적 레이어 자동 숨김 옵션을 통한 렌더링 부하 완화

## 계산식

메가스 포격 예상값은 다음 기준으로 계산합니다.

- **포격 횟수** = `floor(현재 손패 / 2)`
- **발당 피해** = `3 + ceil(현재 배틀 카드 코스트 합계 / 3)`
- **총 피해** = `포격 횟수 × 발당 피해`

다음 라운드 시작 시 예상 손패는 현재 손패, 턴 종료 효과, 라운드 보급 UI의 실제 관측 상태를 바탕으로 계산합니다.

## 예상 포격 대상 표시

메가스의 액티브 스킬로 착지 발판을 선택하는 동안 다음 정보를 표시합니다.

- 화면 안 유효 포격 대상: 빨간 타겟 레티클
- 화면 밖 유효 포격 대상: 화면 가장자리 방향 표시 + 몬스터 이름
- 폭격 범위: 선택 발판 기준 그래프 거리 1~6 발판의 미사일 아이콘 + 거리 `+N`
- Calculator 창: 예상 포격 대상 이름 + 현재 HP

포격 대상은 단순한 화면상 거리 추정이 아닙니다. 선택 발판 기준 그래프 거리 6 이하 후보를 구한 뒤 게임 자체 `Skill.IsVailMonster` 판정을 통과한 몬스터만 후보 목록에 표시합니다.

실제 포격 적중 대상은 이 후보들 중 무작위로 결정되므로, Calculator는 **실제로 맞게 될 몬스터를 미리 예측하지 않습니다.** 표시되는 목록은 현재 선택한 착지 발판에서 포격 대상으로 선택될 수 있는 후보 목록입니다.

## Calculator UI

Calculator 창은 다음 3단계 표시 상태를 지원합니다.

1. **전체 펼침**
2. **다음 라운드 손패 예측 패널만 접기**
3. **완전 접기** — 헤더만 표시

우측 상단 접기 버튼 또는 `C` 키를 누를 때마다 위 순서로 반복 전환됩니다.

중간 단계에서도 메가스 스킬 착지 발판을 선택하는 동안에는 손패 예측 영역 위치에 **예상 포격 대상 목록**이 표시됩니다.

그 외 UI 조작:

- **Windows 시스템 트레이 아이콘 우클릭:** 설정 / 언어 / 정보(About) / 종료 등 프로그램 메뉴
- 상단 타이틀 바 드래그: Calculator 위치 이동
- 창 테두리/모서리 드래그: 크기 조절
- 우측 상단 초기화 버튼: 위치 / 크기 / 접기 상태 초기화
- 현재 손패 우측 토글: 효과 카드 / 배틀 카드 장수 상세
- 포격 상세 토글: 예상 포격 계산 상세
- 전체 손패 경우의 수 토글: 손패별 다음 라운드 예상값 표

## 단축키

단축키는 Astral Party가 포그라운드일 때 동작합니다.

- `C`: Calculator 창 3단계 표시 전환
  - 전체 펼침 → 손패 예측 패널만 접기 → 완전 접기 → 전체 펼침
- `V`: 모든 오버레이 표시 / 숨김 토글
- `X`: 게임 화면 전체 표적 표시 ON/OFF
- `Z`: 폭격 범위 미사일 아이콘 + 거리(`+N`) ON/OFF

게임 화면 표적 표시의 우선순위는 `V > X > Z`입니다.

`C`는 Calculator 창 레이아웃만 변경하며 X/Z 표적 설정과는 독립적입니다.

## 기본 설정

**설정은 Windows 시스템 트레이의 Megas Bullet Calculator 아이콘을 우클릭한 뒤 `설정` 메뉴에서 변경할 수 있습니다.**

새 설정 파일을 생성하는 최초 실행 기준입니다. 기존에 저장한 설정이 있으면 기존 설정값이 우선됩니다.

- 표시 언어: **한국어**
- 게임 화면 타겟 마크: **ON**
- 폭격 범위 미사일 아이콘 + 거리(`+N`): **OFF**
- 카메라 이동 중 표적 표시 숨기기: **ON**

언어는 트레이 아이콘 우클릭 메뉴에서 한국어 / English / 日本語 / 中文 중 변경할 수 있으며 저장됩니다.

## 카메라 이동 중 표적 표시 숨기기

기본값은 **ON**입니다.

스킬 착지 발판을 선택한 상태에서 카메라가 이동해 실제 발판 화면 좌표가 계속 변하면 타겟 레티클, 폭격 범위, 화면 밖 대상 표시를 잠시 숨깁니다.

마지막 좌표 이동 후 약 80ms 동안 좌표가 안정되면 최신 위치로 다시 표시합니다.

이 기능은 카메라 드래그 중 전체 화면 투명 오버레이를 반복해서 합성하면서 발생할 수 있는 성능 저하를 줄이기 위한 옵션이며, X/Z의 저장 설정값 자체를 변경하지 않습니다.

## 최초 실행 및 자동 설치

처음 사용하는 PC에서는 `MegasBulletCalculator.exe`를 한 번 직접 실행하세요.

프로그램이 Astral Party 설치 경로를 확인하고 필요한 BepInEx Unity IL2CPP 구성요소와 Megas Sensor를 자동으로 설치/복구합니다.

BepInEx가 처음 설치된 PC에서는 Astral Party 최초 실행 시 IL2CPP interop 파일 생성 때문에 평소보다 게임 시작이 늦을 수 있습니다. 이는 초기화 과정이며 이후 실행은 보통 더 빨라집니다.

마지막으로 직접 실행한 Calculator EXE 경로가 Sensor의 자동 실행 대상으로 등록됩니다. EXE 위치를 변경했다면 새 위치의 `MegasBulletCalculator.exe`를 한 번 직접 실행하는 것이 좋습니다.

## 자동 실행 및 종료

- 로컬 플레이어가 메가스로 PvE 본게임에 진입하면 Sensor가 Calculator를 자동 실행합니다.
- 메가스가 아닌 플레이어로 플레이하는 판에서는 Calculator가 표시되지 않습니다.
- 메가스 판이 끝나면 Calculator가 정상 종료됩니다.
- 게임 종료 시 Sensor도 종료 경로로 전환됩니다.

## 기존 BepInEx / Shushu Shield Indicator 사용자

이미 호환 가능한 BepInEx가 설치되어 있으면 기존 코어를 불필요하게 덮어쓰지 않고 필요한 Megas Sensor만 추가합니다.

Megas Sensor는 다음 경로에 설치됩니다.

```text
BepInEx\plugins\MegasBulletCalculator\MegasBulletSensor.dll
```

Shushu Shield Indicator와는 별도 Sensor 플러그인과 별도 로컬 UDP 포트를 사용하며 동시 사용을 전제로 설계되었습니다.

기존 다른 모드/플러그인을 임의로 제거하지 않도록 설계되어 있지만, 모든 타사 모드 조합과의 호환성을 보장하지는 않습니다.

## 제거

게임과 Calculator를 모두 종료한 뒤 배포 폴더의

```text
MegasBulletCalculator_Uninstall.exe
```

를 실행하면 Megas Bullet Calculator가 설치한 Sensor와 등록 정보를 제거할 수 있습니다.

공유 BepInEx 구성요소나 다른 플러그인을 임의로 제거하지 않도록 설계되어 있습니다.

## 개인정보 / 통신

현재 버전은 별도 사용자 계정 정보, 비밀번호 또는 개인 데이터를 수집하는 기능이 없습니다.

Sensor와 Calculator 간 상태 전달은 다음 로컬 주소를 사용합니다.

```text
127.0.0.1:38472
```

프로그램은 게임 설치 경로 탐지를 위해 로컬 Steam 설정/라이브러리 정보를 읽을 수 있습니다.

설정, 로그 및 자동 실행 등록 정보는 다음 위치에 저장될 수 있습니다.

```text
%LOCALAPPDATA%\MegasBulletCalculator\
```

## 비공식 도구 및 이용 책임

이 프로그램은 Astral Party 개발사/배급사의 공식 제품이나 공식 지원 도구가 아닙니다.

게임 업데이트, 운영정책 변경 또는 클라이언트 구조 변경으로 인해 언제든지 작동하지 않거나 예상치 못한 문제가 생길 수 있습니다.

프로그램 제작자는 다른 이용자의 플레이를 방해하거나 게임 결과를 조작하기 위한 목적으로 이 도구를 제공하지 않습니다. 그러나 이러한 제작 의도는 게임 운영정책상 사용 허가를 의미하지 않습니다.

사용자는 본인이 이용하는 게임의 이용약관/운영정책을 직접 확인하고 본인의 판단과 책임 하에 사용해야 합니다. 관련 법령상 허용되는 범위에서 원제작자는 프로그램 사용으로 인한 게임 실행 문제, 데이터 또는 설정 손실, 계정 이용 제한 또는 제재, 다른 프로그램이나 모드와의 충돌 등 직접·간접적인 손해를 보증하거나 책임지지 않습니다.

## 배포 파일

공식 배포 ZIP:

```text
MegasBulletCalculator_v1.0.0_Windows.zip
└─ dist\
   ├─ MegasBulletCalculator.exe
   ├─ MegasBulletCalculator_Uninstall.exe
   ├─ README_KO.txt
   ├─ RELEASE_NOTES.txt
   ├─ LICENSE.txt
   ├─ THIRD_PARTY_NOTICES.txt
   ├─ MegasBulletCalculator.build.json
   ├─ SHA256SUMS.txt
   └─ LICENSES\
```

`LICENSE.txt`는 Megas Bullet Calculator 자체의 이용 및 배포 조건입니다.

`THIRD_PARTY_NOTICES.txt`와 `LICENSES` 폴더는 배포물에 포함된 제3자 라이브러리 및 도구의 라이선스/고지용입니다.

GitHub Release Assets에는 배포 ZIP과 별도의 SHA-256 검증 파일을 함께 제공합니다.
